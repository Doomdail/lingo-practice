# Аудит безопасности Lingo Practice — 30 сентября 2026

Проверены исходники версии 0.4.3 (коммит `6158d8b`), исправления подготовлены как **0.4.4**. Проверка начата 30 сентября и завершена 1 октября 2026 года. Это аудит кода, воспроизводимые проверки и проверки браузерных границ, а не сертификация безопасности.

## Что проверено

- Все исполняемые файлы: `background.js`, `content.js`, `youtube.js`, `exercise.js`, `data.js`, `library.js`, `i18n.js`; HTML, CSS и обе локализации.
- Сообщения между вкладкой и фоновым процессом; данные страницы и MAIN world; доступ к хранилищу, импорт/экспорт и отображение недоверенного текста.
- Разрешения, CSP, открытые веб-ресурсы, сетевые запросы и возможность выполнения внешнего кода.
- Скрипт упаковки, состав ZIP, GitHub Actions и история Git: 28 доступных коммитов, 129 уникальных файловых объектов, 3 121 766 байт. Поиск распространённых форматов ключей и токенов не обнаружил совпадений; содержимое игнорируемого ключа подписи не читалось. Неизвестные форматы секретов такой поиск не гарантирует обнаружить.

Некорректный импорт отклоняется. |

## Дополнительное усиление защиты

- Хранилище доступно напрямую только доверенным страницам расширения и фоновому процессу (`TRUSTED_CONTEXTS`). Обработчики операций дожидаются настройки ограничения и не продолжают работу при её ошибке.
- Запросы занятия привязаны к ID расширения, главному фрейму, странице YouTube и идентификатору видео отправителя. Запрос другой записи через обработчик не проходит. Библиотечные операции по-прежнему доступны только `library.html`.
- Загрузка timedtext принимает только обычные HTTPS-адреса YouTube с точным путём, без нестандартного порта, логина/пароля и перенаправлений. Для отсутствующих или слишком больших дорожек остаётся штатный сценарий ошибки/расшифровки.
- Явная CSP запрещает сетевые соединения, формы с навигацией, внешние фреймы и объекты на страницах расширения. До изменения MV3 уже запрещал произвольные внешние скрипты; отсутствие явной CSP не считалось отдельной уязвимостью.
- Git игнорирует файлы ключей и `.env`. Упаковка по фиксированному списку уже защищала архивы от попадания ключа подписи и профилей браузера.
- Новые проверки безопасности включены в GitHub Actions. Зависимости во время работы расширения не добавлены; разрешения остались `activeTab`, `scripting`, `storage`.

## Что уже было защищено

Недоверенные названия, субтитры и ошибки выводятся как текст. Генерация CSV экранирует кавычки/переносы и нейтрализует начальные формулы. Импорт ограничен размером и проверяется до записи; удаление и импорт защищены версиями хранилища. Нет сервера разработчика, аналитики, `eval`, загрузки внешнего исполняемого кода или произвольных URL для открытия вкладок.

GitHub Actions использует закреплённые SHA действий, `contents: read`, отключённое сохранение учётных данных и обычный `pull_request`, без выполнения непроверенного кода с секретами через `pull_request_target`.

## Проверки

- `node --test`: 20 проверок пройдены, включая воспроизведение ошибок до исправления и прохождение после.
- `python tests/security-smoke.py`: настоящий закрытый интерфейс, блокировка подделки ответа/пропуска/подтверждения и прямого доступа к хранилищу; настоящий ввод и импорт SRT работают.
- `python tests/update-smoke.py`: архив содержит ровно разрешённые файлы; обновление с 0.4.2 до 0.4.4 сохраняет ID расширения, ответы, черновик, настройки и статистику.
- `python tests/browser-smoke.py`: живой YouTube пройден в Chromium, Edge и Opera GX; в Chromium дополнительно проверены конфликт двух вкладок, экспорт, очистка и восстановление копии.
- Браузерные проверки используют временные профили. Закрытый интерфейс исследуется привилегированным тестовым драйвером; в продукте нет тестового обхода защиты.
- Независимая итоговая проверка не нашла блокирующих проблем; 20 000 детерминированных примеров перекрывающихся субтитров дали тот же результат, что и версия до изменения алгоритма.

## Границы проверки

- Закрытый Shadow DOM не является полной изоляцией от сайта. Панель остаётся на странице YouTube: уже зарегистрированные скрипты сайта могут наблюдать события клавиатуры. Это отражено в политике конфиденциальности. Для полной изоляции ввода нужен интерфейс на отдельной странице расширения; текущий продукт не предназначен для ввода секретов.
- Локальные JSON/CSV и профиль браузера не зашифрованы самим расширением. Удалённой утечки через найденные пути не обнаружено, но доступ злоумышленника к профилю/учётной записи ОС находится за пределами защиты расширения.
- Настройки аккаунтов GitHub/Google, полномочия издателя, установленный экземпляр у пользователя и работа защиты самих браузеров не менялись и не являются предметом проверки исходников.
- Управление кнопкой расширения и настоящими субтитрами в фирменном Chrome требует ручной проверки: он блокирует используемую автоматическую установку расширений из командной строки.
- Ограничение 2 МБ может отклонить очень длинную дорожку; это явное ограничение доступных ресурсов, текущая тренировка при ошибке сохраняется.
